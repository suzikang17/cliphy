# Supabase for DB + Auth

**Date:** 2026-02-14 · **Category:** Tech · **Revisit?** no

## Why this choice

Generous free tier, built-in Google OAuth, real-time subscriptions, PostgreSQL under the hood

## Options considered

Supabase, Firebase, PlanetScale, raw PostgreSQL

## Tradeoffs

Platform dependency, less control than self-hosted
