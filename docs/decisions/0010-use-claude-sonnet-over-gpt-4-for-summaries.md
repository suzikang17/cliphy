# Use Claude (Sonnet) over GPT-4 for summaries

**Date:** 2026-02-14 · **Category:** Tech · **Revisit?** no

## Why this choice

Best summary quality per dollar. Structured JSON output is reliable. Haiku available for short videos to save costs.

## Options considered

Claude Sonnet, GPT-4o, Gemini, Llama (self-hosted)

## Tradeoffs

Locked into one AI provider. Anthropic API can have rate limits. Could add fallback to GPT later if needed.
