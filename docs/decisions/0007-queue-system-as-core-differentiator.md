# Queue system as core differentiator

**Date:** 2026-02-14 · **Category:** Product · **Revisit?** no

## Why this choice

No competitor does batch queueing well, solves the 'I have 15 tabs open' problem, natural upgrade path to Pro

## Options considered

Single video summaries, queue/batch system, playlist import

## Tradeoffs

More complex to build than single-video, need good UX for queue management
