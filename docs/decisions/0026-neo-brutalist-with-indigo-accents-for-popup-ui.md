# Neo-brutalist with indigo accents for popup UI

**Date:** 2026-02-23 · **Category:** Design · **Revisit?** no

## Why this choice

Neo-brutalist base gives personality (hard shadows, bold fonts, black borders). Swapped yellow/pink for indigo for cohesive palette. User preferred rounded-lg over rounded-xl.

## Options considered

Soft/rounded, minimal flat, dark mode, YouTube-native, neo-brutalist casual, 2 hybrid mixes

## Tradeoffs

Hard black shadows could feel heavy at scale but works in small popup. Indigo is safe/professional, less personality than yellow/pink but more cohesive.
