# Build as Chrome extension, not web app

**Date:** 2026-02-14 · **Category:** Product · **Revisit?** no

## Why this choice

Chrome extension lives where users already are (YouTube in the browser). One-click queue from any YouTube page. No context switching. Chrome Web Store provides distribution.

## Options considered

Chrome extension, web app, desktop app, mobile app

## Tradeoffs

Desktop-only (no mobile). Chrome-only (no Firefox/Safari at launch). Extension review process. MV3 limitations on background processing.
