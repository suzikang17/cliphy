# Dynamic context section: freeform AI-chosen title + emoji over predefined set

**Date:** 2026-03-04 · **Category:** Product · **Revisit?** no

## Why this choice

Freeform lets the AI pick what naturally fits — "Recipe" for cooking, "Steps" for tutorials, "Key Concepts" for lectures. A predefined set would miss edge cases and feel rigid. The emoji adds visual distinction at zero cost.

## Options considered

A) Freeform title + emoji (chosen)
B) Predefined set of ~10 section types
C) Freeform title only (no icon)

## Tradeoffs

AI could pick weird titles or emojis. Mitigated by prompt guidelines with examples. UI handles any string gracefully.
