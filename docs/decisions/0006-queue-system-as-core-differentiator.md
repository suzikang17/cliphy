# Queue system as core differentiator

**Date:** 2026-02-14 · **Category:** Product · **Revisit?** no

## Why this choice

No competitor has batch queueing. Matches real user behavior (hoard tabs, process later). Creates a workflow, not just a tool. Drives retention through daily use.

## Options considered

Single-video summarizer (like competitors), queue/batch system, playlist import, Watch Later integration

## Tradeoffs

More complex to build than single-video. Queue UI adds development time. Background processing needs careful state management.
